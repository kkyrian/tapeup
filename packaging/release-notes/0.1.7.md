## What's new

- **Importing is much faster.** A batch of four 30-minute files now takes about 8 seconds instead of about 33. TapeUp brings in up to four files at once.
- **Files already in the right format skip encoding.** A 48 kHz stereo AAC file now comes in almost instantly.
- **The import window shows what each file is doing.** A file says Encoding when TapeUp is converting its sound, and Copying when it isn't.

## Install

Download **TapeUp.dmg** below and drag TapeUp to Applications, or:

```
brew install kkyrian/tap/tapeup
```

Already on TapeUp? It updates itself when you're not recording, or use **Check for Updates…** in the ··· menu.

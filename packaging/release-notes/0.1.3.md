## What's new

- **Speakers are labeled automatically.** When a transcript is ready, TapeUp finds who spoke when, so you no longer need to click Label speakers. Imports still follow their Label speakers switch.
- **Your name comes first.** When you say who was in a meeting or name a voice, your own name is the first suggestion. You set it on the People page. TapeUp doesn't add you on its own, so a meeting you missed won't list you.
- **Open at login is on** for new installs. You can turn it off in Settings.
- **The floating timer stays on one line** after the first hour.

## Install

Download **TapeUp.dmg** below and drag TapeUp to Applications, or:

```
brew install kkyrian/tap/tapeup
```

Already on TapeUp? It updates itself when you're not recording, or use **Check for Updates…** in the ··· menu.

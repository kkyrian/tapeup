## What's new

- **Saving a long recording no longer squeezes the time onto two lines.** While TapeUp saves, the button shows only "Saving…" and the time, and hides the shortcut, which does nothing until the save is done.

## Install

Download **TapeUp.dmg** below and drag TapeUp to Applications, or:

```
brew install kkyrian/tap/tapeup
```

Already on TapeUp? It updates itself when you're not recording, or use **Check for Updates…** in the ··· menu.

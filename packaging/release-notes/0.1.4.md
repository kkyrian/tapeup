## What's new

- **Keep the transcript, drop the audio.** Once a recording has a transcript, the new button beside the trash removes only the audio and keeps everything else, with Undo right there. Handy for meetings you only need in writing. Right-click a recording for the same thing.
- **Transcript-only recordings say so.** The card reads "Transcript only", and lists show a small page mark before the length.
- **The trash says what it takes:** the recording and its transcript.

## Install

Download **TapeUp.dmg** below and drag TapeUp to Applications, or:

```
brew install kkyrian/tap/tapeup
```

Already on TapeUp? It updates itself when you're not recording, or use **Check for Updates…** in the ··· menu.

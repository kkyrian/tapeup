## What's new

- **The Record button is blue until you start recording.** It turns red as Stop only while TapeUp is recording. A red button in the panel now always means a recording is on.
- **A ··· button on every recording.** Hover over a recording to find it. It has the same actions as right-click, including Remove Audio. Show in Finder moved there from the hover buttons. Remove Audio is always listed for a recording with audio. It is greyed out until the transcript and speaker labels are done.
- **Import from the panel.** A new import button sits next to the folder button above your recordings.

## Install

Download **TapeUp.dmg** below and drag TapeUp to Applications, or:

```
brew install kkyrian/tap/tapeup
```

Already on TapeUp? It updates itself when you're not recording, or use **Check for Updates…** in the ··· menu.

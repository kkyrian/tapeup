## What's new

- **Copy path now gives your agent the speakers' names.** After you label speakers, **Copy path** points your agent to a transcript where each line starts with the speaker's name. **Copy transcript** already worked this way.
- **The import bar moves while a long file copies.** Before, it stayed at zero until the file was done.

## Install

Download **TapeUp.dmg** below and drag TapeUp to Applications, or:

```
brew install kkyrian/tap/tapeup
```

Already on TapeUp? It updates itself when you're not recording, or use **Check for Updates…** in the ··· menu.

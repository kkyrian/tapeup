## What's new

- **Copy path gives your agent the names.** Once you've labeled speakers, the transcript it points to is the one where each line starts with who spoke. Copy transcript already did this.
- **The import bar moves while a file copies.** Bringing in one long recording, the bar at the bottom of the Import window now fills as it copies, instead of waiting at zero until the file is done.

## Install

Download **TapeUp.dmg** below and drag TapeUp to Applications, or:

```
brew install kkyrian/tap/tapeup
```

Already on TapeUp? It updates itself when you're not recording, or use **Check for Updates…** in the ··· menu.
